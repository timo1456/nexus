# Nexus

Nexus is a Flask-powered network and infrastructure management platform for visualising network topology, tracking device availability, investigating incidents, and exploring rule-based troubleshooting. It includes a demo-friendly simulated network so the product can be explored without physical networking equipment.

The application is designed as a portfolio-grade foundation: modular Flask application factory, SQLAlchemy data models, secure authentication, organisation-scoped networks, interactive topology, monitoring history, incident records, API endpoints, automated tests, and production deployment guidance.

> Monitoring real devices requires explicit authorisation and network reachability. The demo network uses simulated observations and does not claim to monitor real infrastructure.
